# Refer & Earn — 3 Referral Types

User Account > Refer & Earn now has three circular choices: User, Vendor, Delivery Partner.

Admin controls three independent reward amounts under System > Settings > Referral.
- User referral reward
- Vendor referral reward
- Delivery partner reward

Vendor and delivery partner rewards are credited only after Admin approval. Customer referral keeps the existing first-delivered-order rule.

Referral status is visible on the same User screen. Codes are target-specific (`USR`, `VEN`, `RDR`) and deep links use the corresponding Expo app scheme.
